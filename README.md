# Pocket Zoom

**Системное увеличение экрана и режим мыши для Retroid Pocket 6 (Android 13).**

Автор: **I.Lednev** · Версия **1.0** · [GitHub](https://github.com/I-Lednev/PocketZoom) · [Releases](https://github.com/I-Lednev/PocketZoom/releases/latest)

> **Важно.** Приложение создано специально для **Retroid Pocket 6** под Android 13.
> На других устройствах оно **не тестировалось** и может не работать.
> Это не приложение из Google Play: оно устанавливается вручную и использует
> системную службу специальных возможностей Android.

---

## Что умеет

- **Увеличение экрана по M2** — одним нажатием включает полноэкранный зум,
  повторным — возвращает обычный вид. Масштаб и область запоминаются.
- **Работает поверх любых игр и приложений** — не нужен root, ADB или ПК.
- **Режим мыши вместе с зумом** — M2 включает и выключает указатель Retroid.
- **Слежение за курсором** — увеличенный экран едет за правым стиком.
- **R2 / L2** — плавно менять масштаб; **D-pad** и **тачпад** в правом нижнем
  углу — перемещаться по увеличенному экрану.
- **Скорость курсора** — ползунок 0,2×–3,0×.
- **Правый стик — курсор** — можно поменять местами указатель и колесо.
- **Мягкая вибрация** при движении курсора.
- **Проверка обновлений** прямо из приложения через GitHub Releases.

## Установка

1. Скачайте `PocketZoom-1.0.apk` из раздела
   [Releases](https://github.com/I-Lednev/PocketZoom/releases/latest).
2. Установите APK. Разрешите установку из этого источника, если система спросит.
3. **Android 13:** откройте «Настройки → Приложения → Pocket Zoom → меню ⋮ →
   Разрешить ограниченные настройки», иначе переключатель службы специальных
   возможностей может быть недоступен.
4. «Настройки → Специальные возможности → Pocket Zoom — увеличение экрана» →
   включить. Либо нажмите в приложении «Открыть настройки спец. возможностей».
5. Выдайте разрешение **«Изменение системных настроек»** (кнопка в приложении),
   чтобы переключать режим мыши вместе с зумом.
6. Для обновлений разрешите Pocket Zoom **установку неизвестных приложений**
   («Настройки → Приложения → Специальный доступ → Установка неизвестных
   приложений → Pocket Zoom»).

После установки новой версии поверх старой служба специальных возможностей
обычно переподключается сама. Если зум перестал работать — откройте настройки
специальных возможностей и включите службу заново.

> **Переход с RetroZoom.** Pocket Zoom использует новый пакет
> `com.pocketzoom`. Перед установкой удалите старую версию RetroZoom: настройки
> и назначение кнопки M2 нужно будет сделать заново.

## Использование

1. В приложении нажмите **«Назначить кнопку»** и нажмите **M2**.
2. Выберите масштаб ползунком (1,5×–7,0×).
3. Нажмите **«Включить»**. Экран увеличится, появится уведомление с кнопками
   управления.
4. Переключитесь в игру. M2 работает в фоне.

| Кнопка | Действие |
| --- | --- |
| **M2** | включить / выключить зум (и режим мыши) |
| **R2** | приблизить |
| **L2** | отдалить |
| **D-pad** | перемещение по увеличенному экрану |
| **Тачпад** в правом нижнем углу | перемещение пальцем |

Пока зум включён, R2, L2 и D-pad перехватываются приложением и не доходят до
игры. Тачпад тоже не передаёт касания в игру.

### Режим мыши

В карточке **«Мышь»**:

- **«Включать режим мыши вместе с зумом»** — M2 включает указатель и выключает
  его обратно.
- **«Центрировать по курсору мыши»** — зум следует за указателем.
- **«Скорость курсора»** — чувствительность 0,2×–3,0× (та же настройка, что
  «Cursor speed» в настройках Retroid).
- **«Правый стик — курсор»** — меняет местами указатель и колесо.
- **«Вибрация при движении курсора»** — короткие мягкие толчки, сила
  регулируется.

Настройки записываются в конфигурацию мыши Retroid и применяются при включении
зума. Если вы меняли их в настройках Retroid, включите и выключите
соответствующий переключатель в Pocket Zoom, чтобы приложение записало свой
вариант.

### Обновления

В карточке **«Обновления»** нажмите **«Проверить обновления»**. Приложение
обращается к последнему релизу на GitHub:

- во время проверки показывается прогресс и надпись «Проверка обновлений…»;
- если версия новее, появляется номер версии, краткое описание обновления
  (на английском, из GitHub Release) и кнопка **«Скачать и установить»**;
- APK скачивается с GitHub, после чего открывается системный установщик.
  Android всегда спрашивает подтверждение — тихая установка без root невозможна.

По умолчанию приложение также проверяет обновления при запуске (не чаще раза в
12 часов); это можно отключить галочкой.

## Ограничения

- Увеличение **системное**: увеличивается весь экран, включая элементы игры.
- Системный магнификатор **не выходит за края экрана**: у верхней/нижней/боковой
  границы вид останавливается. Чёрных полей и «зума за границу», как в Steam
  Deck, здесь нет — это ограничение Android, а не приложения.
- Оранжевая рамка по периметру — **системный индикатор увеличения Android**
  (4 dp). Приложение её не рисует и не может отключить обычными средствами.
- Кнопки M1/M2 иногда не доходят до фоновых приложений. Если M2 не
  определяется, назначьте её на клавишу клавиатуры в
  **Handheld settings → Input → Back keys**, затем повторите назначение в
  Pocket Zoom.
- Прошивка Retroid показывает собственный тост **«V Mouse»** при переключении
  режима мыши. Это окно системного приложения; Pocket Zoom не может его скрыть,
  но автоматически возвращает центр увеличения на место после появления тоста.
- Правый стик и оси геймпада не перехватываются приложением: они остаются у
  системы. Для игры они работают как обычно, пока режим мыши выключен.

## Сборка

Нужны **JDK 17**, **Android SDK 34** и **Gradle 8.7+**.

```bash
# локально
./gradlew assembleRelease        # если добавлен wrapper
# или
gradle assembleRelease
```

APK появится в `app/build/outputs/apk/release/`.

### Подпись

Релизы подписываются стабильным ключом, иначе Android не установит обновление
поверх установленной версии. Создайте `keystore.properties` в корне проекта:

```properties
storeFile=keystore/pocketzoom-release.jks
storePassword=...
keyAlias=pocketzoom
keyPassword=...
```

Сам ключ и `keystore.properties` **не коммитятся** (см. `.gitignore`). Для
GitHub Actions добавьте секреты репозитория:

| Секрет | Значение |
| --- | --- |
| `KEYSTORE_BASE64` | keystore в base64 |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `pocketzoom` |
| `KEY_PASSWORD` | пароль ключа |

### Выпуск обновления

1. Поднимите `versionCode` и `versionName` в `app/build.gradle`.
2. Обновите `release-notes.md` (краткое описание на английском).
3. Поставьте тег и отправьте его:
   ```bash
   git tag v1.0.1
   git push origin v1.0.1
   ```
4. GitHub Actions соберёт подписанный APK и создаст релиз. Приложение увидит
   новую версию при следующей проверке.

## Структура

- `MainActivity` — настройки, статусы, обновления, диагностика.
- `ZoomAccessibilityService` — зум, клавиши, режим мыши, вибрация.
- `PanPad` — прозрачный оверлей-тачпад.
- `MouseCursor` — чтение курсора из `/dev/input/event8`.
- `MouseMode` / `MouseTuning` — режим мыши и конфигурация Retroid.
- `UpdateChecker` — GitHub Releases, скачивание APK.
- `ApkProvider` — выдача APK системному установщику.
- `AppState` — настройки в `SharedPreferences`.
- `Notifications` / `ActionReceiver` — постоянное уведомление.
