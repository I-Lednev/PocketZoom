Pocket Zoom 1.0 — first public release

- System full-screen magnification for Retroid Pocket 6 (Android 13).
- M2 toggles zoom and the Retroid mouse mode together.
- R2/L2 zoom; D-pad and on-screen trackpad panning.
- Optional cursor following and soft haptic feedback.
- Cursor speed and left/right stick swap.
- Built-in update check from GitHub Releases.

Only tested on Retroid Pocket 6. Not tested on other devices.
